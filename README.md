В данном репозитории лежат 4 файла с лабораторными работами по математической статистику, сделанными мной на 2 и 3 курсах университета:
### ДЗ дисперсионный анализ.Rmd
Однофакторный дисперсионный анализ (One-Way ANOVA) для оценки влияния факторов на доходы населения в регионах.
### ДЗ по кластеризации.ipynb
Сегментация сотрудников компании для разработки мер повышения эффективности. Включает предварительный анализ, выбор числа кластеров (метод локтя, силуэт, дендрограммы), K-Means и DBSCAN, интерпретацию кластеров и рекомендации.
### ДЗ проверка гипотез.Rmd
Проверка гипотез на языке R: F-тест Фишера для сравнения дисперсий, t-тест Стьюдента и Уэлча для средних, критерий Вилкоксона, тесты для биномиальных распределений и критерии согласия с нормальным законом (Пирсон, Жарк-Бера, Андерсон-Дарлинг и др.).
### ДЗ регрессия, данные по странам.html
Построение и анализ модели линейной регрессии на данных о странах: корреляционный анализ, обучение модели, оценка качества и интерпретация.
